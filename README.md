# Poolser website

The public product website for Poolser. Repository initialized; implementation has not started.

The site will introduce Poolser, show sanitized screenshots of the published apps, provide accurate platform download links and a Go to app link, and host stable support and privacy URLs for App Store metadata. Viewing it requires no wallet connection, API key or portfolio data.

## Related repositories

- [brand](https://github.com/poolser-app/brand): shared guide, original artwork and colour tokens.
- [native](https://github.com/poolser-app/native): Mac/iPhone/iPad apps, native screenshots and current app privacy policy.
- [web](https://github.com/poolser-app/web): the working browser application.

Use a reviewed brand commit and keep required exports locally. Keep marketing content aligned with published releases, distinguish Mac and iOS availability, explain read-only monitoring and the Mac browser-wallet handoff accurately, and retain the Uniswap non-affiliation statement. Privacy content must describe the actual native, web and hosting behaviour before publication.

The first implementation should be static, responsive and accessible, with light/dark appearance, reduced-motion support, page metadata and a working preview before production publication. Hosting and the final domain are not configured yet.
